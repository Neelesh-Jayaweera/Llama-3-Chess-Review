# ♟️ Chess Review AI: Tactical Dataset Generator

An advanced Chess analysis tool built with **Streamlit**, **python-chess**, and **Groq (Llama-3.3-70b)**.

## 🚀 Features
- **Chess.com Integration**: Fetch and review your personal game archives directly.
- **X-Ray Spatial Sensors**: Detects direct threats and defenders.
- **Llama-3.3 Analysis**: Uses Groq's high-speed inference for Grandmaster-level move explanations.

## 🛠️ Tech Stack
- **Frontend**: Streamlit
- **Logic**: python-chess
- **AI Model**: Llama-3.3-70b-versatile (via Groq)
